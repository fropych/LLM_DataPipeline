# ML Data Pipeline

Универсальный ML-пайплайн для сбора, чистки, разметки данных и обучения модели, построенный с помощью **Claude Code Workflow Studio**. Пайплайн полностью управляется LLM-агентами — от загрузки данных до финального отчёта.

Пользователь запускает воркфлоу, отвечает на вопросы (какой датасет, какая стратегия чистки, какой метод разметки), а агенты выполняют всю работу: пишут скрипты, запускают их, анализируют результаты и генерируют отчёты.

В качестве демонстрации пайплайн был прогнан на задаче классификации новостей **AG News** (4 класса). Результаты прогона — в разделе [Пример прогона](#пример-прогона).

## Воркфлоу в Claude Code Workflow Studio

Пайплайн спроектирован как визуальный воркфлоу в CC Workflow Studio — расширении для VS Code, позволяющем строить графы из LLM-агентов, скиллов и точек взаимодействия с пользователем.

### Архитектура

Воркфлоу состоит из 4 групп агентов, каждая отвечает за свой этап ML-пайплайна:

**Группа 1 — DataCollectionAgent**

![DataCollectionAgent](assets/Screenshot%202026-03-22%20at%2021.39.12.png)

Сбор данных: загрузка датасета из HuggingFace/Kaggle, выбор второго источника (web scraping или REST API), объединение в единый формат, EDA с визуализациями.

**Группа 2 — DataQualityAgent**

![DataQualityAgent](assets/Screenshot%202026-03-22%20at%2021.40.01.png)

Контроль качества: автоматическое детектирование проблем (пропуски, дубликаты, выбросы, дисбаланс классов), выбор стратегии чистки пользователем, применение чистки, сравнительный отчёт до/после.

**Группа 3 — AnnotationAgent**

![AnnotationAgent](assets/Screenshot%202026-03-22%20at%2021.40.14.png)

Разметка данных: авторазметка (zero-shot классификация или keyword rules), генерация спецификации разметки, проверка качества (Cohen's kappa), экспорт в LabelStudio, точка HITL для ручной проверки.

**Группа 4 — ActiveLearningAgent**

![ActiveLearningAgent](assets/Screenshot%202026-03-22%20at%2021.40.26.png)

Active Learning: эксперимент с выбором стратегий (entropy vs random или margin vs random), обучение финальной модели, компиляция итогового отчёта.

### Ключевые особенности

- **5 точек принятия решений** — пользователь управляет ходом пайплайна через интерактивные вопросы (источник данных, стратегия чистки, метод разметки, стратегия AL, подтверждение качества)
- **Ветвление** — воркфлоу идёт по разным путям в зависимости от выбора: scraping vs API, conservative vs aggressive, zero-shot vs keyword rules, entropy vs margin
- **Суб-агенты** — тяжёлые задачи делегируются специализированным агентам (Sonnet), которые самостоятельно пишут и запускают скрипты
- **14 переиспользуемых скиллов** — атомарные операции (load-dataset, detect-issues, fix, compare, auto-label, al-cycle и др.), каждый скилл можно вызывать отдельно
- **Human-in-the-loop** — после авторазметки пайплайн останавливается для ручной проверки примеров с низкой уверенностью
- **Визуальный трекинг** — активная группа подсвечивается на канвасе во время выполнения
- **Воспроизводимость** — все шаги сохраняются как Python-скрипты в `scripts/`, итоговый `run_pipeline.py` запускает весь пайплайн одной командой

## Запуск

```bash
# Установка зависимостей
uv sync

# Запуск воркфлоу через Claude Code (интерактивный режим с агентами)
# В VS Code: открыть воркфлоу в CC Workflow Studio и нажать Run

# Запуск сгенерированного пайплайна (после прогона воркфлоу)
uv run python run_pipeline.py

# Без HITL-паузы
uv run python run_pipeline.py --skip-hitl

# С определённого шага
uv run python run_pipeline.py --from-step 7
```

## Структура проекта

```

├── run_pipeline.py            # Запуск полного пайплайна одной командой
├── config.yaml                # Конфигурация источников данных

├── AI_REPORT.md               # Подробный отчёт по прогону (5 разделов)
├── agents/                    # Классы агентов
├── scripts/                   # Python-скрипты для каждого шага (1_*, 2_*, 3_*, 4_*, 5_*)
├── data/
│   ├── raw/                   # Сырые данные из источников
│   ├── cleaned/               # Очищенные данные
│   └── labeled/               # Размеченные данные + экспорт LabelStudio
├── models/                    # Обученные модели (.joblib)
├── reports/                   # Markdown-отчёты
│   ├── eda_plots/             # Графики EDA
│   └── quality_plots/         # Графики качества данных
├── notebooks/                 # Jupyter-ноутбуки (EDA, AL-эксперимент)
└── assets/                    # Скриншоты воркфлоу
```

## Пример прогона

Воркфлоу был запущен на задаче **классификации новостей AG News** (4 класса: World, Sports, Business, Sci/Tech). Пользователь выбрал: HuggingFace как источник, conservative стратегию чистки, keyword rules для разметки, entropy vs random для AL.

### Результаты

| Этап | Метрики |
|------|---------|
| Сбор данных | 127 600 строк, 4 класса, идеальный баланс |
| Чистка | 4 493 выброса обрезаны, 0 строк удалено |
| Разметка | Cohen's kappa = 0.46, 36.6% отправлено на ручную проверку |
| Active Learning | Entropy F1 = 0.499 vs Random F1 = 0.489 |
